# SEO baseline 2026-09

Fecha de auditoría: 2026-09-17.

## Observado
- Mundaca: Next.js App Router con home, legales, sitemap y robots; antes de esta fase no tenía hubs de productos ni soluciones indexables.
- Foodies: `foodies-landing` Next.js separado de la app operativa; antes de esta fase no tenía sitemap, robots ni páginas comerciales dedicadas.
- Carbono: aplicación React/Vite con landing pública en `/` y numerosas rutas autenticadas; metadata y schema existían en `index.html`, pero faltaba sitemap/robots y política dinámica de noindex.

## Sin datos disponibles
No se observaron datos de Search Console en este entorno. No se inventan volumen, posiciones, impresiones, clics ni CTR.

## Cambios de esta fase
Se agregaron hubs corporativos, páginas de soluciones, rutas comerciales y recursos Foodies, schemas de entidad/producto, sitemaps, robots y controles de indexación de app.

## Medición mensual
Registrar: query, URL objetivo, impresiones, clics, CTR, posición media y conversiones/contactos. Fuente: Google Search Console.
