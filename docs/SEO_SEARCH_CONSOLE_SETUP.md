# Search Console setup

1. Crear una Domain Property para `mundacasolutions.com`.
2. Verificarla mediante DNS con el registro indicado por Google.
3. Enviar los sitemaps públicos:
   - `https://mundacasolutions.com/sitemap.xml`
   - `https://foodies.mundacasolutions.com/sitemap.xml`
   - `https://carbonozero.mundacasolutions.com/sitemap.xml`
4. Inspeccionar la home corporativa, `/productos`, las dos páginas corporativas y las landings comerciales.
5. Solicitar indexación inicial sólo después de comprobar respuesta 200, canonical y HTML inicial.
6. Revisar mensualmente queries, páginas, impresiones, clics, CTR, posición media y conversiones/contactos disponibles.

No automatizar el login ni guardar credenciales en el repositorio. Los sitelinks no se pueden forzar; la arquitectura sólo mejora la capacidad de Google para inferir la jerarquía.
